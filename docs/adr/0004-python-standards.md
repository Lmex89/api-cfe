# Python standards with a shrinking baseline

We use Ruff for lint, import ordering, Google-style docstrings, complexity and formatting, and mypy for types, rather than separate overlapping tools. Dev-only pinned dependencies and local pre-commit hooks keep production dependencies and deployment unchanged. Existing violations are grandfathered with per-file Ruff rule ignores, deferred format exclusions and per-module mypy error ignores; this avoids an unrelated mass rewrite while letting us remove exceptions incrementally. Mypy is strict outside its baseline but ignores missing imports. These broad exceptions also hide new violations in legacy files, and local hooks are bypassable and not CI enforcement; reviewers must help shrink the baseline and check changed legacy code. Automated limits approximate, but cannot guarantee, sound SOLID design or English docstrings.
